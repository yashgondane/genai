REPAIRAGENT CODEBASE REFACTORING LOG
================================================================================
GOAL: 
  1. Remove ALL hardcoded values from the codebase (single source of truth in config.json).
  2. Radically simplify the frontend UX for practical developer use:
     - Quick Code Debugger: Copy-paste/type code in any language (C++, Python, Java, JS, Rust, Go, C, etc.) with instant problem metrics, root cause diagnosis, unified diffs, and 1-click replace.
     - Local Folder Repair Agent: Point to ANY directory on the user's laptop, auto-scan files, analyze bugs across the project, display per-file problem metrics + diffs, and provide a 1-click 'Accept & Apply Changes to Disk' (with automatic backup & revert).
     - Settings & API Keys: Clean key management and health status.

WHAT TRIGGERED THIS TASK:
  - User requested removing unnecessary research tabs (Defects4J project pickers, legacy experiment folders, hardcoded academic benchmarks).
  - User wanted simple, direct code debugging by typing or copy-pasting.
  - User wanted to point the agent directly to any directory on their laptop, get suggested fixes with problem metrics, and accept & replace changes directly in their actual project files.

================================================================================
ARCHITECTURE & NEW CAPABILITIES
================================================================================
1. Central Configuration (repair_agent/config.json):
   - Single source of truth for version, host/port, models, supported languages, benchmarks, and paths.

2. REST Endpoints in api_server.py:
   - GET  /api/config            -> Returns full config.json dynamically
   - GET  /api/models            -> Returns active models based on saved API keys
   - GET  /api/status            -> Returns Python, environment, and API key status
   - POST /api/keys              -> Saves OpenAI & Anthropic keys to local .env
   - POST /api/debug             -> Quick code debugger (accepts code snippet, language, description; returns root cause, problem metrics, severity, full fixed code, unified diff)
   - POST /api/project/scan      -> Local folder repair (scans directory from laptop, detects source files, analyzes with LLM, outputs per-file problems, severity, root cause, and git-style unified diffs)
   - POST /api/project/apply     -> Writes accepted fixes directly to the files on disk with automatic timestamped backups in .repairagent_backups/
   - POST /api/project/revert    -> Reverts applied files from backup snapshot

3. Simplified Frontend (frontend/index.html & app.js & style.css):
   - Sidebar with 3 focused tabs:
     [1] Quick Debug: Instant code editor with language pills (C++, Python, Java, JS, TS, Rust, Go, C, etc.), sample loader, metrics chips (Severity, Type, Confidence), root cause card, diff viewer, and 'Replace in Editor' / 'Copy Fixed Code' actions.
     [2] Folder Repair: Directory input for any local project, optional instructions, scan button, overview stats banner, per-file issue cards with diffs, individual file apply buttons, and 'Accept & Apply All Changes to Disk'.
     [3] Settings & Keys: API key management and server health checks.
